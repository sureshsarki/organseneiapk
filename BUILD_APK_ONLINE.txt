═══════════════════════════════════════════════════════════════════
GITHUB ACTIONS WORKFLOW FILE
═══════════════════════════════════════════════════════════════════

Create this file in your repo:
Location: .github/workflows/android-build.yml

Copy-paste this content:

---FILE START---
name: Android Build

on:
  push:
    branches: [ main, master ]
  pull_request:
    branches: [ main, master ]
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    
    steps:
    - name: Checkout code
      uses: actions/checkout@v3
    
    - name: Set up JDK 17
      uses: actions/setup-java@v3
      with:
        distribution: 'temurin'
        java-version: '17'
        cache: 'gradle'
    
    - name: Grant execute permission for gradlew
      run: chmod +x gradlew
    
    - name: Build Debug APK
      run: ./gradlew assembleDebug
    
    - name: Upload APK
      uses: actions/upload-artifact@v3
      with:
        name: ear-sensei-debug.apk
        path: app/build/outputs/apk/debug/app-debug.apk
---FILE END---

═══════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

BUILD FAILS - "SDK not found":
→ Workflow installs SDK automatically, this shouldn't happen
→ Check build logs in Actions tab
→ Ensure JDK version is 17 in workflow file

BUILD FAILS - "Gradle error":
→ Check that gradle-wrapper.properties exists
→ Ensure gradlew has execute permissions
→ Try: workflow_dispatch trigger to rebuild

APK WON'T INSTALL - "App not installed":
→ Enable "Install from Unknown Sources" on phone
→ Uninstall any previous version first
→ Check Android version (needs 8.0+)

BUILD SUCCEEDS BUT NO APK:
→ Check Artifacts section (might be collapsed)
→ Ensure upload-artifact step ran successfully
→ Download and unzip the artifact
