═══════════════════════════════════════════════════════════════════
  UNDERSTANDING THE CODE FLOW
═══════════════════════════════════════════════════════════════════

1️⃣ USER OPENS APP
   MainActivity.kt loads
   ↓
   Checks permissions
   ↓
   Shows dashboard with today's stats from DatabaseHelper
   ↓
   User sees: Daily Exposure %, Listening Time, Volume

2️⃣ USER TAPS "START MONITORING"
   MainActivity starts VolumeMonitorService
   ↓
   Service creates persistent notification
   ↓
   Service starts repeating task every 10 seconds

3️⃣ EVERY 10 SECONDS (while monitoring):
   VolumeMonitorService runs:
   ↓
   Reads current volume from Android AudioManager
   ↓
   Passes to HearingDamageCalculator
   ↓
   Calculator estimates dB and calculates damage
   ↓
   Stores in database via DatabaseHelper
   ↓
   Checks if alert needed (>50%, >75%, >100%)
   ↓
   Updates notification with current status
   ↓
   Repeat...

4️⃣ USER RETURNS TO APP
   MainActivity.onResume() called
   ↓
   Queries database for latest stats
   ↓
   Updates all UI elements
   ↓
   User sees updated Daily Exposure %

5️⃣ USER TAPS "STOP MONITORING"
   Service stopped
   ↓
   Notification removed
   ↓
   Data remains in database for history


═══════════════════════════════════════════════════════════════════
  KEY ANDROID CONCEPTS USED
═══════════════════════════════════════════════════════════════════

🎯 ACTIVITY (MainActivity.kt)
   What: The visible screen user interacts with
   Like: A window in a desktop app
   Job: Display UI, handle button clicks

⚙️ SERVICE (VolumeMonitorService.kt)
   What: Background worker that runs without UI
   Like: A daemon process in Linux
   Job: Keep monitoring even when app is closed

💾 SQLite DATABASE (DatabaseHelper.kt)
   What: Local database stored on phone
   Like: A simple Excel file with SQL queries
   Job: Store every listening session with timestamp

📱 LAYOUT XML (activity_main.xml)
   What: Defines how UI looks (buttons, text, cards)
   Like: HTML for Android
   Job: Design the screen appearance

🔔 NOTIFICATIONS
   What: System messages shown in notification tray
   Like: Toast notifications in Windows
   Job: Alert user about hearing risks

📡 FOREGROUND SERVICE
   What: Service with persistent notification
   Like: A task in Task Manager you can see
   Job: Prevents Android from killing the service


═══════════════════════════════════════════════════════════════════
  MODIFYING THE APP (For Future Development)
═══════════════════════════════════════════════════════════════════

Want to change the UI colors?
→ Edit: app/src/main/res/layout/activity_main.xml
   Change: android:textColor="#1976D2" to your color

Want to adjust monitoring interval?
→ Edit: VolumeMonitorService.kt
   Change: MONITORING_INTERVAL = 10000L (milliseconds)

Want to change safe limits?
→ Edit: HearingDamageCalculator.kt
   Modify: SAFE_EXPOSURE_MAP with your dB/time values

Want to add new features?
→ Start by reading MainActivity.kt
   Follow the code flow above
   Add new buttons in activity_main.xml
   Add click handlers in MainActivity.kt

  GRADLE FILES EXPLAINED
═══════════════════════════════════════════════════════════════════

build.gradle (project level)
├─ Defines Kotlin and Android plugin versions
└─ Sets up repositories (where to download libraries)

app/build.gradle (app level)
├─ Defines app ID: com.organsensei.earsensei
├─ Sets min Android version: API 26 (Android 8.0)
├─ Sets target version: API 34 (Android 14)
├─ Lists dependencies (libraries used):
│  • androidx.core - Core Android libraries
│  • androidx.appcompat - Backward compatibility
│  • material - Material Design components (cards, buttons)
│  • cardview - Card layouts in UI
└─ Build configuration (debug vs release)

settings.gradle
└─ Tells Gradle this is a project called "EarSensei"

gradle.properties
└─ Performance settings for build process
